feat: disable online update in the mirror build

- lib/update.js: add MIRROR_NO_UPDATE flag (true)
  - checkUpdate() short-circuits and returns a disabled state; it no longer
    queries GitHub for tags / releases
  - handleUpdateOp() rejects every update operation
  - autoUpdateIfNeeded() was already a no-op (`skipped: manual-only`)
- client.js: the update button now reads "更新已禁用 / Updates disabled"
  and is permanently disabled
- README(.zh-CN): document that online update is turned off

Rationale: this mirror is published manually by the maintainer. Letting the
plugin self-update against a repository it does not own the release flow of
would only produce spurious "update available" prompts.
